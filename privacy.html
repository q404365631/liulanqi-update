隐私政策

更新日期 2026-11-13　·　适用版本 v0.3.5 及以后

一句话说明：AI浏览器是一款完全在你电脑本地运行的桌面浏览器。开发者没有服务器、没有账号系统、没有埋点统计，你的浏览数据、密码、书签一律不上传到开发者任何位置。唯一的云端功能是「百度网盘备份」，它把数据加密后存进你自己的百度网盘，开发者同样无法读取。

一、我们处理哪些数据，存在哪里

数据类型存储位置说明
书签、历史、下载记录、设置本机 %APPDATA%\AI浏览器\data纯本地文件，不上传
网站密码本机使用 Windows 系统级加密（DPAPI）存储，与当前 Windows 用户绑定，拷到别的电脑无法解密
我的资料卡（姓名/手机/邮箱等）本机AES 加密存储；不进任何备份；仅在你主动点「AI 填表」时用于填写当前网页
AI 记忆（你浏览过的页面摘要）本机可在设置里逐条删除或一键清空

百度网盘备份（可选）你自己的百度网盘见第二节，端到端加密

二、百度网盘备份（可选功能）

这是本应用唯一会把数据送出本机的功能，必须由你主动扫码授权才会启用，且可以随时关闭。

1. 申请了哪些权限

  • 百度账号基础信息（用于显示"已授权：你的昵称"）
  • 百度网盘文件读写权限，但实际只操作一个固定路径：/apps/liulanqi-sync/liulanqi-sync.lqs
  • 不读取你网盘中的其他任何文件，不修改、不分享、不遍历你的其他数据

2. 上传了什么

书签、网站密码、浏览器设置、AI 记忆。打包成一个文件，加密后上传。

不会上传：浏览历史、下载的文件、我的资料卡、百度授权令牌、同步口令本身。

3. 加密方式（端到端加密）

  • 算法：AES-256-GCM（带认证的对称加密，防篡改）
  • 密钥来源：由你自己设置的「同步口令」通过 scrypt（N=16384, r=8, p=1）派生 32 字节密钥，每次加密使用随机 salt(16B) 与随机 IV(12B)
  • 同步口令只保存在你的电脑本地（加密存储），从不上传、不写进备份文件、不发给百度
  • 因此：百度网盘上只有一段密文。没有你的同步口令，百度解不开，开发者也解不开——这就是"端到端加密"
  • 换电脑恢复时需要输入同一个同步口令，口令不对会直接解密失败（GCM 认证失败），不会得到错误数据

4. 授权前你会看到什么

点击「扫码授权」时，应用先弹出说明页，逐条列出：应用名称、申请的权限项、会上传什么、不会上传什么、加密方式、如何撤销、隐私政策链接。你点「同意并继续」后才会打开百度授权窗口；点「取消」则不会发起任何授权请求。

5. 如何停止同步 / 删除云端数据

  • 停止同步：设置 → 百度网盘 →「停止同步（解除授权）」。立即清除本机百度令牌、停止自动备份，不会再有任何数据上传。
  • 删除云端数据：同一个弹窗里选「解除并删除云端文件」，应用会调用百度网盘接口删除 /apps/liulanqi-sync/liulanqi-sync.lqs，再解除授权。
  • 只在网盘端删除：你也可以直接在百度网盘 App/网页里删掉 我的应用数据 / liulanqi-sync 目录下的文件。
  • 撤回授权：在百度账号「授权管理」中取消对「AI浏览器」的授权，应用立即失去访问能力（即使本机令牌未清）。

三、AI 功能

  • AI 功能需要你自己填入第三方 AI 服务商（如 DeepSeek、通义千问、智谱、Kimi、OpenAI 等）的 API Key。
  • 使用 AI 功能时，被处理的文本（例如你要翻译的网页内容、你问的问题）会从你的电脑直接发送到你所选的服务商，由该服务商按其隐私政策处理。开发者不经手、不中转、不存储。
  • API Key 加密保存在本机，不上传。
  • 翻译功能在未配置 Key 时会退化为免费公共翻译接口（Google / MyMemory），发送内容仅为待翻译文本。
  • 「AI 填表」只填写表单字段，提交按钮永远由你本人点击。

四、我们不做的事

  • ❌ 不收集浏览记录、密码、网盘文件内容
  • ❌ 不上传数据到开发者服务器（没有服务器）
  • ❌ 不出售、不共享、不交换任何用户数据
  • ❌ 不投放广告、不做用户画像、不接入第三方统计 SDK
  • ❌ 备份中不含资料卡、不含明文密码落盘

五、数据的保存期限与删除

  • 本地数据：由你掌握，可在设置中清除，或卸载后手动删除数据目录。
  • 百度网盘备份：只保留最新一个文件，每次备份覆盖同名文件；删除方式见第二节第 5 条。
  • AI 记忆与对话：最多保留 100 条，可随时一键清空。

六、未成年人保护

本应用不面向未成年人收集任何个人信息，也不针对未成年人做任何推荐或营销。

七、政策变更

本政策如有变更，会更新本页面的「更新日期」，重大变更会在应用内提示。继续使用即视为接受更新后的政策。
