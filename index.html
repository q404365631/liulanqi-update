FAQ
你可能想问的
要花钱吗？+
软件本身完全免费、无广告。AI 功能需要你自己配一个模型 API Key，选免费模型（美团 LongCat、glm-4-flash）就零成本，选 deepseek 级别每月也就几块钱。
我的数据安全吗？+
我们没有服务器，也不注册账号。书签密码存你电脑本地（Windows 系统级加密），网盘备份用你自己的口令做 AES-256 端到端加密——我们和百度都读不到内容。
AI 会不会乱点乱提交？+
自动操作会先给执行计划，你点"开始执行"它才动；填表只填不提交，提交键永远由你按，任何一步都能中途停。
支持哪些系统？+
Windows 10 / 11 64 位，安装包可以自己选安装盘，不会偷偷装进 C 盘。
能导入 Chrome 的书签吗？+
能。书签面板里有「导入书签」，选 Chrome/Edge 导出的 html 文件即可，自动去重。
