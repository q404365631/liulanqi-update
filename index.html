What it does

01

自动操作网页 / Agent 2.0

先出执行计划给你确认，然后跨网站自己点、自己填。查到的价格和结论自动整理成表格报告。

02

看过的网页自动存成本地摘要。问"上周那篇讲显卡的说了什么"，它跨页面跨会话回答，附当时的链接。

04

整页翻译 + 划词问答 / Translate

外文网页一键翻成中文（悬停看原文），选中文字即问即答，报错看不懂直接截图丢给它。

书签密码记忆用你的口令 AES-256 加密，自动存进你自己的百度网盘，换电脑一键拉回。

标签整理 / Organizer

标签开成一锅粥？AI 按主题自动分组上色、揪出重复页面，给你一键关闭按钮。

FAQ

你可能想问的

要花钱吗？+
软件本身完全免费、无广告。AI 功能需要你自己配一个模型 API Key，选免费模型（美团 LongCat、glm-4-flash）就零成本，选 deepseek 级别每月也就几块钱。
我的数据安全吗？+
我们没有服务器，也不注册账号。书签密码存你电脑本地（Windows 系统级加密），网盘备份用你自己的口令做 AES-256 端到端加密——我们和百度都读不到内容。
AI 会不会乱点乱提交？+
自动操作会先给执行计划，你点"开始执行"它才动；填表只填不提交，提交键永远由你按，任何一步都能中途停。
支持哪些系统？+
Windows 10 / 11 64 位，安装包可以自己选安装盘，不会偷偷装进 C 盘。
能导入 Chrome 的书签吗？+
能。书签面板里有「导入书签」，选 Chrome/Edge 导出的 html 文件即可，自动去重。
