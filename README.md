# AI 浏览器（liulanqi）

> 一个带 AI 助手的 Windows 浏览器：说一句话，让它替你搜、替你点、替你总结。

基于 Chromium 内核 + Electron 外壳，界面和操作习惯与 Chrome 一致，额外内置了 AI 能力和小人物助手。

![主界面](images/screenshot-main.png)

## 它和普通浏览器有什么不同

### 🤖 说到就能做到
在对话框里输入 **"打开百度"**、**"在淘宝搜一下蓝牙耳机"**、**"登录这个网站"**，
AI 会自己打开网页、点击链接、填写搜索框，你只需要看结果。

> 不需要记命令，也不用手动一步步操作。

### 💬 让 AI 读懂你正在看的页面
- **📄 总结此页**：一键把当前网页提炼成要点
- **✂️ 划词问 AI**：选中任何文字，浮出"问 AI"气泡，翻译/解释/总结
- **📷 截图问 AI**：截取当前页面，让 AI 解读图片内容
- **🐛 帮看报错**：网页报错时自动捕获，用人话解释原因并给出解决办法（别家浏览器没有）
- **🌐 整页翻译**：不配 Key 也能用（免费翻译接口自动降级），配了 Key 质量更高
- **🪄 AI 全能表单**：资料卡填一次，任何网页点「🪄」自动填姓名/手机/邮箱——你检查后自己点提交

### 🧑‍💼 小人物助手
右下角有个会动的小家伙：
- 点它就打开聊天框，直接打字使唤
- 有表情和动作：思考时天线闪、你说话时它听、任务完成会开心蹦
- 没事会提醒你"上次看的那个要不要接着看"

### 🎙️ 语音对话
- 🎤 点一下开始说话，识别后自动发送
- 🔊 AI 回复自动朗读（Windows 本地语音合成，不联网）

## 数据放哪、换电脑怎么办（重装不丢）

### 数据存哪

**跟着安装盘走，不占 C 盘**：装在 `E:\ailiulanqi`，数据就在 `E:\ailiulanqi\data`（书签、密码、设置、AI 记忆）+ `E:\ailiulanqi\user`（网站登录状态）。设置 → 数据同步 → 「本机数据位置」可以直接看到。

密码用 Windows 系统级加密（DPAPI）存储；旧版本存在 C 盘 AppData 的数据，升级后第一次启动会**自动搬到安装盘**。

### 换电脑三条路（都不需要给应用任何网盘授权）

| 方式 | 怎么用 | 适合 |
|---|---|---|
| **网盘同步文件夹**（推荐） | 设置 → 数据同步 → 选网盘客户端的同步文件夹（自动检测 OneDrive/坚果云/百度网盘），设一个同步口令 | 日常自动备份 |
| **WebDAV** | 填坚果云/Nextcloud/群晖的 WebDAV 地址 | 有 NAS 或坚果云的重度用户 |
| **导出/导入文件** | 「导出到文件」生成加密文件，微信/U 盘拷走，「从文件导入」 | 不想装网盘客户端 |

| 网盘 | 上传（备份） | 恢复到新电脑 |
|---|---|---|
| OneDrive | ✅ 全自动 | ✅ 全自动 |
| 坚果云 | ✅ 全自动 | ✅ 全自动 |
| 百度网盘 | ✅ 自动（客户端「备份 → 文件夹备份」选本文件夹，免费） | 🖱 手动一步：把 liulanqi-sync.lqs 下载下来 → 「从文件导入」 |
| 阿里云盘 | ✅ 自动 | 🖱 手动一步：同上 |

### 重装系统 / 卸载重装，数据会丢吗？

**不会。** 两道保险：

1. **卸载时**：安装脚本自动把数据搬到安装盘根目录的 `AI浏览器-数据备份` 文件夹（卸载器删不到）
2. **重装后第一次启动**：浏览器自动扫描所有磁盘的常见位置，找到旧数据就**自动恢复**——启动后小人物会告诉你找回多少书签和密码

> 🔒 所有同步内容用你自己的口令做 **AES-256-GCM 端到端加密**：口令只在本机、从不上传，网盘上只有密文。口令丢了数据就解不开，请记牢。
>
> 📖 逐步教程：[数据同步使用教程](https://ai.useaiwriter.com/sync-guide.md)

## 新标签页可以自己定制

默认那排常用网站（百度、哔哩哔哩、知乎…）都能改：

- **删除**：鼠标移到图标上，点右上角的 **×**
- **添加**：点末尾的 **＋**，填名称和网址；也可以点"从书签里选一个"直接从你的收藏里挑
- **恢复默认**：页面底部"恢复默认网站"

设置自动保存在本机，下次打开还在。

## 支持 Chrome 扩展

设置 → 扩展 → **添加扩展**，选一个解包好的 Chrome 扩展目录（含 manifest.json）即可。
Manifest V2 和 V3 都支持。

> 说明：Electron 未实现部分 Chrome 专有接口，少数依赖这些接口的扩展可能功能受限
> （如依赖 chrome.identity 登录、部分企业策略接口）。内容脚本类扩展（去广告、改页面样式、
> 翻译划词等）通常可正常工作。

## 下载安装

在右侧 **Releases** 里下载最新的安装包，双击安装即可（约 77MB）。

> 安装向导里可以**自己选择安装到哪个盘**（默认 C 盘，可以改成 D/E 盘）——建议装到非 C 盘，数据会跟着走。

## 常见问题

**Q：提示"未知发布者"不敢装？**
A：正常的，因为没买数字签名证书（一年几百到几千元）。点"更多信息 → 仍要运行"即可。

**Q：AI 说"没配 API key"？**
A：去设置页按上面步骤填一个。留空时 AI 对话是占位回复，但翻译和填表仍然可用。

**Q：让它打开网页没反应？**
A：先确认设置页 AI 状态是"已配置"，并且 key 有余额/没被限流。部分免费 key 有调用频率限制。

**Q：重装系统数据会丢吗？**
A：不会。卸载时数据被自动保送到安装盘根目录，重装后第一次启动自动扫描找回（书签、密码、AI 记忆都在）。

**Q：同步的加密口令忘了怎么办？**
A：无法找回，加密数据解不开。建议用自己记得住的，或记在密码管理器里。

**Q：会收集我的数据吗？**
A：浏览记录、书签、密码都只存在你自己的电脑上（密码用系统加密），数据文件就在安装目录里。只有你主动使用 AI 时，对话内容才会发给你配置的那家 AI 服务商。同步功能只上传你自己加密后的密文。详见[隐私政策](https://ai.useaiwriter.com/privacy.html)。
