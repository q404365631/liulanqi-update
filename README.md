# AI 浏览器（liulanqi）

> 一个带 AI 助手的 Windows 浏览器：说一句话，让它替你搜、替你点、替你总结。

基于 Chromium 内核 + Electron 外壳，界面和操作习惯与 Chrome 一致，额外内置了 AI 能力和小人物助手。

![主界面](images/screenshot-main.png)

## 它和普通浏览器有什么不同

### 🤖 说到就能做到
在对话框里输入 **"打开百度"**、**"在淘宝搜一下蓝牙耳机"**、**"登录这个网站"**，
AI 会自己打开网页、点击链接、填写搜索框，你只需要看结果。

> 不需要记命令，也不用手动一步步操作。

### 💬 让 AI 读懂你正在看的页面
- **📄 总结此页**：一键把当前网页提炼成要点
- **✂️ 划词问 AI**：选中任何文字，浮出"问 AI"气泡，翻译/解释/总结
- **📷 截图问 AI**：截取当前页面，让 AI 解读图片内容
- **🐛 帮看报错**：网页报错时自动捕获，用人话解释原因并给出解决办法（别家浏览器没有）

### 🧑‍💼 小人物助手
右下角有个会动的小家伙：
- 点它就打开聊天框，直接打字使唤
- 有表情和动作：思考时天线闪、你说话时它听、任务完成会开心蹦
- 没事会提醒你"上次看的那个要不要接着看"

### 🎙️ 语音对话
- 🎤 点一下开始说话，识别后自动发送
- 🔊 AI 回复自动朗读（Windows 本地语音合成，不联网）

## 新标签页可以自己定制

默认那排常用网站（百度、哔哩哔哩、知乎…）都能改：

- **删除**：鼠标移到图标上，点右上角的 **×**
- **添加**：点末尾的 **＋**，填名称和网址；也可以点"从书签里选一个"直接从你的收藏里挑
- **恢复默认**：页面底部"恢复默认网站"

设置自动保存在本机，下次打开还在。

## 支持 Chrome 扩展

设置 → 扩展 → **添加扩展**，选一个解包好的 Chrome 扩展目录（含 manifest.json）即可。
Manifest V2 和 V3 都支持。

> 说明：Electron 未实现部分 Chrome 专有接口，少数依赖这些接口的扩展可能功能受限
> （如依赖 chrome.identity 登录、部分企业策略接口）。内容脚本类扩展（去广告、改页面样式、
> 翻译划词等）通常可正常工作。

## 数据同步（不需要自己搭服务器）

### 方式零：百度网盘扫码直传（v0.1.6 新增，最省事）

不用装网盘客户端、不用找文件夹，**扫码就能把数据加密备份到你自己的百度网盘**。

设置 → 百度网盘（扫码）→ 点「扫码授权」→ 手机百度App扫码 → 自动完成授权。

之后：

- 改了书签、密码、AI 记忆 → **几秒后自动加密上传**
- 也可选择**定时备份**：每 5 / 15 / 30 分钟 / 1 小时兜底上传一次
- 换电脑：装好浏览器 → 扫码授权 → 点「从百度恢复」，数据就回来了

> 备份文件存放在你网盘的 `/apps/liulanqi-sync/` 目录下，名为 `liulanqi-sync.lqs`，**内容是加密的**，只有你的同步口令能解开。
>
> 每个使用者扫的是**自己的**百度账号，备份进**自己的**网盘空间，不经过任何中间服务器。

**使用前提**：先设一个同步口令（至少 4 位），务必记牢——口令丢了，云端文件就解不开。

📖 **逐步图文教程**：[百度网盘备份使用教程](baidu-backup-guide.md)（含扫码、备份频率选择、换电脑恢复、常见问题）

### 方式一：网盘同步文件夹（通用，四种网盘都行）

百度网盘、阿里云盘、OneDrive、坚果云这些网盘在电脑上都有个**同步文件夹**，放进去的文件会自动传到云端。

设置 → 数据同步 → **同步文件夹**：软件会自动检测你电脑上已有的网盘文件夹，点一下就能选用；也可以点「选择」手动指定。

再设一个**同步口令**（至少 4 位，每台设备要一样），打开**自动同步**即可：

- 改了书签、密码，几秒后自动写入并上传
- 换电脑/重装：选同一个文件夹 + 同一个口令 → 点「从文件夹恢复」
- 别的设备更新了，右下角小人物会提醒你恢复

> 浏览器只往这个文件夹里写一个 liulanqi-sync.lqs 文件，其余文件不碰。

**四种网盘都能用，区别只在"恢复到新电脑"那一步：**

| 网盘 | 上传（备份） | 恢复到新电脑 |
|---|---|---|
| OneDrive | ✅ 全自动 | ✅ 全自动 |
| 坚果云 | ✅ 全自动 | ✅ 全自动 |
| 百度网盘 | ✅ 自动备份（客户端「备份 → 文件夹备份」选本文件夹，免费） | 🖱 手动一步：在网盘客户端把 liulanqi-sync.lqs 下载下来 → 「从文件导入」 |
| 阿里云盘 | ✅ 自动备份（客户端「备份无忧」） | 🖱 手动一步：同上 |

> 也就是说：百度网盘、阿里云盘完全可以用来备份——日常改动自动上传；只是换新电脑时要手动下载一次文件。

> 不想折腾网盘？用「导出到文件」生成加密文件，微信/U 盘拷到新电脑「从文件导入」，效果一样。

### 方式二：WebDAV（坚果云、Nextcloud、群晖原生支持）

设置 → 数据同步，三件事：

- **导出成文件**：生成一个加密文件，自己拷到别的电脑导入
- **导入文件**：恢复书签、密码、设置、AI 记忆
- **WebDAV 云同步**：填自己的 WebDAV 地址即可（坚果云、Nextcloud、群晖等都有免费额度），
  一键上传/恢复

🔒 **端到端加密**：所有数据用你自己设的口令做 AES-256-GCM 加密，
云端或文件里只有密文，服务商看不到你的书签和密码。口令丢了数据就解不开，请记牢。

## 第一次使用：配置 AI

### 用什么模型？看你想达到什么效果（2026-11 调研）

| 档位 | 填什么 | 效果 | 花费 |
|---|---|---|---|
| **免费入门** | 服务商选「智谱」，模型 `glm-4-flash`，视觉模型 `glm-4v-flash` | 日常对话/翻译/总结流畅；AI 自动操作简单任务够用，复杂任务偏笨 | 全免费（128K 上下文） |
| **性价比推荐** | DeepSeek 官方（`https://api.deepseek.com/v1`，模型 `deepseek-chat`）；或智谱 `glm-5.3-flash`（自带视觉，不用另填视觉模型） | **AI 自动操作流畅（每步几秒）**，复杂任务成功率高，JSON 稳定 | 极低（DeepSeek 输入约 $0.14/百万 token 级） |
| **效果顶配** | `qwen-max`、Kimi K2.5（256K 超长上下文）、GPT 系（需中转） | 复杂跨站比价、长文档阅读最强 | 中-高 |

> 💡 免费通道（如各类中转站的高规格模型）也能跑，但通常**限流且每步要等 30-60 秒**——想体验流畅的 AI 自动操作，推荐 deepseek-chat 或 glm-5.3-flash 这个级别。
>
> 各服务商「自定义」填法：智谱 `https://open.bigmodel.cn/api/paas/v4` ｜ DeepSeek `https://api.deepseek.com/v1` ｜ 阿里百炼 `https://dashscope.aliyuncs.com/compatible-mode/v1`。免费政策可能调整，以各家定价页为准。


AI 功能需要一个大模型的 API Key（自己申请，通常有免费额度）：

1. 打开浏览器 → 点右上角 **⋮** → **设置** → 找到 **AI 助手** 区块
2. **服务商**选一个（推荐 **智谱清言 GLM**，有免费模型；或 DeepSeek，便宜好用）
3. 把申请到的 **API Key** 填进去
4. 点 **"测试连接"** 确认通，再点 **"保存 AI 设置"**

配好后所有 AI 功能立刻可用。

## 常见问题

**Q：提示"未知发布者"不敢装？**
A：正常的，因为没买数字签名证书（一年几百到几千元）。点"更多信息 → 仍要运行"即可。

**Q：AI 说"没配 API key"？**
A：去设置页按上面步骤填一个。留空时 AI 功能是占位回复。

**Q：让它打开网页没反应？**
A：先确认设置页 AI 状态是"已配置"，并且 key 有余额/没被限流。部分免费 key 有调用频率限制。

**Q：同步的加密口令忘了怎么办？**
A：无法找回，加密数据解不开。建议用自己记得住的，或记在密码管理器里。

**Q：会收集我的数据吗？**
A：浏览记录、书签、密码都只存在你自己的电脑上（密码用系统加密）。只有你主动使用 AI 时，
对话内容才会发给你配置的那家 AI 服务商。同步功能也只上传你自己加密后的密文。
